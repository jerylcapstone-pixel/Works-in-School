## 🚀 Projects Included

### 1. **FinalReq** - Attendance & Time Tracking System
- **Tech:** Java (Swing GUI), db4o Database
- **Purpose:** Track employee/student attendance and work hours
- **Key Skills:** Desktop GUI development, Database management, Object-oriented design

### 2. **Omandam** - Object-Oriented Programming Demo
- **Tech:** Java (NetBeans)
- **Purpose:** Demonstrate OOP concepts (inheritance, polymorphism, abstraction)
- **Key Skills:** Class design, Inheritance hierarchies, Polymorphic behavior

### 3. **Omandam Repair System** - Computer Repair Appointments
- **Tech:** Java Backend, MySQL Database
- **Purpose:** Manage computer repair services and customer appointments
- **Key Skills:** System design, Database normalization, Business logic

### 4. **AcadERP** - Academic Enterprise Resource Planning
- **Tech:** PHP, MySQL, JavaScript, Bootstrap
- **Purpose:** Comprehensive management system for educational institutions
- **Key Features:**
  - Department and Program management
  - Course scheduling and enrollment
  - Student and faculty management
  - Tuition and financial tracking
  - Automated database migrations
  - Multi-theme support (dark/light mode)
- **Key Skills:** Full-stack web development, Database design, System architecture

### 5. **StyleSync** - Hair Salon Booking System
- **Tech:** PHP, MySQL, Bootstrap 5, Font Awesome
- **Purpose:** Online appointment booking and service management for salons
- **Key Features:**
  - User registration and authentication
  - Appointment scheduling system
  - Service catalog management
  - Admin dashboard
  - Appointment history and archives
  - Social media integration
- **Key Skills:** Web application development, User authentication, UI/UX design, Business logic

### 6. **Semi-Finals** - Flask File Management System
- **Tech:** Python (Flask), MySQL, Bootstrap
- **Purpose:** Web-based file/image upload and management system
- **Key Features:**
  - Secure file uploads (Werkzeug)
  - MySQL database integration
  - Responsive Bootstrap UI
  - Logging and error handling
- **Key Skills:** Python web development, REST principles, Database integration
